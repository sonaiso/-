## القوانين التي يُنفذها PR #32

### 1. الشهادة تتطلب صحة مُثبَتة ✅

```python
# من d1_proof.py
is_certified ⟹ corr_result.is_correct
is_certified ⟹ ¬failure_set.has_critical_failure()
```

لا يمكن شهادة أي مرشح دون اجتياز جميع فحوصات Corr_D1.

### 2. الرتبة العالية ≠ الصحة ✅

```python
# من d1_rank_policy.py
# أبعاد الرتبة هي تفضيل، ليس برهان
rank_vector.overall_rank ∈ [0, 1]  # نقاط التفضيل
proof.is_certified ∈ {True, False}  # علامة الصحة
```

الرتبة توجه الاختيار بين المرشحات الصالحة. البرهان يحدد الصلاحية.

### 3. D1 لا يدعي الجذر/الوزن/المعنى ✅

```python
# اختبارات منع الترقية في test_d1_anti_promotion.py
assert not hasattr(syllable_candidate, 'root')
assert not hasattr(syllable_candidate, 'wazn')
assert not hasattr(syllable_candidate, 'meaning')
```

D1 يثبت فقط:
- ✅ هذه الذرات تشكل مقطعًا صحيحًا (البنية)
- ✅ حدود المقطع صحيحة
- ✅ حفظ الذرات والترتيب محفوظ

D1 لا يدعي:
- ❌ هذا المقطع يحتوي على حروف الجذر
- ❌ هذا المقطع يطابق الوزن X
- ❌ هذا المقطع له معنى Y

### 4. القابلية للعكس مُثبَتة، ليست مُدَّعاة ✅

```python
# من syllable_candidate.py:263-278
def _verify_reversibility(self, original_atoms):
    try:
        reversed_atoms = reverse_syllable_candidate(self)
        expected = original_atoms[self.span[0]:self.span[1]]
        return reversed_atoms == expected  # اختبار فعلي
    except:
        return False
```

قابلية عكس الأثر **مُختبَرة**، ليست **مُفترَضة**.

### 5. البرهان مطلوب للشهادة ✅

```python
# من syllable_candidate.py:119-135
def is_valid(self):
    if self.proof is not None:
        return self.proof.is_certified  # استخدم البرهان

    # احتياطي للفحوصات القديمة
    has_critical_failure = self.failures.has_critical_failure()
    has_blocker = any(r.is_blocker() for r in self.residuals)
    return not (has_critical_failure or has_blocker)
```
