# U₇-C عقد تعاقدات الجملة السطحية - ملخص بالعربية

## الملخص التنفيذي

**المجال**: U₇-C = حامل عقد تعاقدات الجملة السطحية

**الغاية**: حماية تعاقدات الجملة السطحية قبل استخراج الجذر

**الموقع المعماري**:
```
U₇-A عقد ما قبل الوزن
  ↓
U₇-B حارس السطح اللفظي (يحمي العلامات داخل الكلمة الواحدة)
  ↓
U₇-C عقد تعاقدات الجملة السطحية (يحمي التعاقدات بين الكلمات)
  ↓
U₈ مرشح الجذر والجذع
```

**الحالة**: ✅ **المرحلة الثانية مكتملة** (البنى الأساسية منفّذة)

---

## الفصل المعماري الجوهري: U₇-B مقابل U₇-C

### فرق السؤال الأساسي

**U₇-B يسأل**: "ما العلامات داخل هذه الكلمة؟"
- ما العلامات الموجودة **داخل هذه الكلمة**؟
- ما السوابق واللواحق المحمية؟
- هل هذه الكلمة آمنة لاستخراج الجذر في U₈؟

**U₇-C يسأل**: "ما التعاقدات بين الكلمات؟"
- ما التوافقات الموجودة **بين الكلمات**؟
- هل الصفات تطابق الأسماء؟
- هل الأفعال تطابق الفواعل؟
- هل جمع التكسير عاقل أم غير عاقل حسب السياق؟

### لماذا هذا الفصل دستوري؟

بعض الظواهر اللغوية **لا يمكن فهمها على مستوى الكلمة**:

#### 1. العاقلية: واضحة فقط في سياق المطابقة

```
الرجال صالحون → عاقل (مطابقة جمع مذكر)
الكتب كثيرة → غير عاقل (مطابقة مفرد مؤنث مع جمع التكسير)
```

#### 2. التأنيث المعنوي مقابل الحقيقي: واضح فقط في المطابقة

```
الشمس طلعت → تأنيث معنوي (لا علامة، لكن الفعل يطابق)
فاطمة جاءت → تأنيث حقيقي (علامة ة + مطابقة)
```

#### 3. سلوك مطابقة جمع التكسير: واضح فقط في الجملة

```
رجال قليلون → مطابقة جمع مذكر (عاقل)
جبال عالية → مطابقة مفرد مؤنث (غير عاقل)
```

#### 4. مطابقة الفعل والفاعل: تحتاج الكلمتين

```
كتب الطالب → مطابقة فعل-فاعل
كتبت الطالبة → مطابقة فعل-فاعل-جنس
```

**القانون الدستوري**:
```
علامة لا تُفهم إلا في تعاقد
```

## القوانين الدستورية الستة

### القانون 7C.1: العلامة لا تُفهم إلا في تعاقد

تحليل الكلمة الواحدة غير كافٍ لـ:
- تحديد العاقلية
- التمييز بين أنواع الجنس
- التنبؤ بسلوك المطابقة

### القانون 7C.2: التعاقد ≠ الإعراب

U₇-C يراقب أنماط المطابقة.
U₇-C **لا** يعيّن الإعراب النهائي.

```
مسموح: number_agreement_hint = POSSIBLE
ممنوع: final_irab = NOMINATIVE
```

### القانون 7C.3: التعاقد ≠ الوظيفة

U₇-C يراقب العقود السطحية.
U₇-C **لا** يعيّن الوظائف النحوية.

```
مسموح: agreement_edge_type = VERB_SUBJECT
ممنوع: this_is_fa3il = TRUE
```

### القانون 7C.4: الحافة السطحية ≠ الحكم النحوي

حواف المطابقة ملاحظات، وليست علاقات نحوية.

### القانون 7C.5: لا حكم قبل العلاقات

الوظائف النحوية تحتاج تحليلًا علائقيًا كاملًا.
U₇-C يفتح المسارات المحتملة فقط.

### القانون 7C.6: جمع التكسير يحتاج عقدًا متعدد الأبعاد

جموع التكسير تحتاج تحليلًا من أكثر من 10 أبعاد قبل استخراج الجذر.

## البنى الأساسية

### 1. وحدة عقد تعاقدات الجملة السطحية

**الغاية**: تمثيل كلمة واحدة مع معلومات المطابقة على مستوى الجملة

**الحقول الأساسية**:
```python
surface: str                          # السطح الأصلي
protected_core: str                   # من U₇-B
root_input: str                       # من U₇-B
root_input_permission: RootInputPermission  # قد يُرفع بواسطة U₇-C

broken_plural_guard: BrokenPluralGuardNode  # حارس جمع التكسير
transitivity_potential: TransitivitySurfacePotential  # احتمال التعدي
weak_radical_risk_vector: WeakRadicalRiskVector  # خطر الاعتلال

agreement_edges: Tuple[str, ...]      # حواف المطابقة
rationality_surface_hint: RationalityHint  # إشارة العاقلية
gender_surface_hint: GenderSurfaceHint  # إشارة الجنس
number_surface_hint: NumberSurfaceHint  # إشارة العدد

permission_elevated_by_agreement: bool  # هل رُفع الترخيص بالمطابقة؟
```

**الحقول الممنوعة** (حظر دستوري):
- `root`, `stem`, `weight`, `pattern` (U₈/U₉)
- `meaning`, `dalalah`, `ifadah` (U₁₅)
- `hukm`, `final_irab` (U₇+)
- `fa3il`, `maf3ul`, `mubtada`, `khabar` (التحليل النحوي)

### 2. عقدة حارس جمع التكسير (متعددة الأبعاد)

**الغاية**: حماية شاملة لجموع التكسير قبل U₈

**الأبعاد العشرة (+)**:

1. **بُعد النمط**: `broken_pattern_hint` (فِعَال، فُعُول، مَفَاعِل)
2. **استرجاع المفرد**: `singular_candidate_path`، `singular_requires_lexicon`
3. **الحالة الاشتقاقية**: `singular_jamid_potential`، `singular_mushtaq_potential`
4. **النوع الوجودي**: `entity_noun_potential`، `adjective_potential`
5. **مصدر الصفة**: `adjective_source_hint` (اسم فاعل، صفة مشبهة)
6. **عقود الجنس**:
   - `gender_surface_hint`
   - `real_feminine_hint` (تأنيث حقيقي)
   - `semantic_feminine_hint` (تأنيث معنوي)
   - `grammatical_feminine_agreement_hint` (تأنيث نحوي)
7. **العاقلية**: `rationality_surface_hint`
8. **سلوك المطابقة**: `agreement_edges`
9. **مسار التعدي**: `transitivity_path_hint`
10. **ضعف الجذر**: `weak_radical_risk`
11. **الدليل المعجمي**: `lexical_attestation_required`
12. **الترخيص**: `root_input_permission` (عادةً DEFERRED)

**مثال: رجال**
```python
BrokenPluralGuardNode(
    surface="رجال",
    broken_pattern_hint="فِعَال",
    singular_candidate_path="رجل",
    singular_requires_lexicon=True,
    rationality_surface_hint=HUMAN_POSSIBLE,
    gender_surface_hint=MASCULINE_POSSIBLE,
    entity_noun_potential=POSSIBLE,
    root_input_permission=DEFERRED,
    residuals={"singular_not_certified"}
)
```

### 3. حافة المطابقة السطحية

**الغاية**: تمثيل ملاحظة مطابقة بين كلمتين

**الأنواع**:
- `NOUN_ADJECTIVE`: اسم - صفة
- `VERB_SUBJECT`: فعل - فاعل
- `MUBTADA_KHABAR`: مبتدأ - خبر
- `NA3T_MAN3UT`: نعت - منعوت
- `BROKEN_PLURAL_ADJECTIVE`: جمع تكسير - صفة

**مثال: الكتب ↔ كثيرة**
```python
AgreementSurfaceEdge(
    edge_type=BROKEN_PLURAL_ADJECTIVE,
    source_unit_id="kutub_unit",       # الكتب
    target_unit_id="kathira_unit",     # كثيرة
    number_agreement_hint=POSSIBLE,
    gender_agreement_hint=POSSIBLE,
    broken_plural_feminine_singular_hint=POSSIBLE,
    non_rational_plural_feminine_agreement_hint=POSSIBLE
)
```

## الأنواع الخمسة للتأنيث

### 1. التأنيث الحقيقي
**العلامة**: ة/ات
**مثال**: فاطمة، طالبات
**الكشف**: العلامة السطحية موجودة

### 2. التأنيث المعنوي
**العلامة**: لا توجد (معنوي فقط)
**مثال**: الشمس، الأرض
**الكشف**: المطابقة بلا علامة سطحية

### 3. التأنيث النحوي
**العلامة**: قائم على المطابقة
**مثال**: حسب السياق والمطابقة
**الكشف**: ملاحظة نمط المطابقة

### 4. مطابقة جمع التكسير كمفرد مؤنث
**النمط**: جمع تكسير غير عاقل + صفة مفرد مؤنث
**مثال**: الكتب كثيرة
**الكشف**: حافة بين جمع التكسير ومفرد مؤنث

### 5. الجمع غير العاقل يُعامل معاملة المفرد المؤنث
**النمط**: جمع غير عاقل يُعامل كمفرد مؤنث
**مثال**: الجبال عالية
**الكشف**: سلوك المطابقة في الجملة

## منطق رفع الترخيص

### تأثيرات ترخيص U₇-C

**الرفع**: DEFERRED → ALLOWED (مع دليل)
```
رجال (DEFERRED في U₇-B)
  + مطابقة مع صالحون
  → rationality_hint = HUMAN_POSSIBLE
  → قد يُرفع الترخيص (مع دعم معجمي)
```

**التأكيد**: ALLOWED → ALLOWED (مع دليل)
```
كتاب (ALLOWED في U₇-B)
  + مطابقة مع جميل
  → الجنس/العدد مؤكد
  → الترخيص مؤكد
```

**الخفض**: لا يُنفّذ بواسطة U₇-C
- U₇-C لا يخفض الترخيصات أبدًا
- يرفع أو يؤكد فقط مع دليل

### تحليل U₇-C (مستوى الجملة)

**كشف حافة المطابقة**:
```python
AgreementSurfaceEdge(
    edge_type=BROKEN_PLURAL_ADJECTIVE,
    source_unit_id="kutub_unit",       # الكتب
    target_unit_id="kathira_unit",     # كثيرة
    number_agreement_hint=POSSIBLE,    # نمط جمع/مفرد
    gender_agreement_hint=POSSIBLE,    # مطابقة مؤنث

    non_rational_plural_feminine_agreement_hint=POSSIBLE
```

**استنتاج العاقلية**:
```
الكتب + كثيرة (مفرد مؤنث)
→ rationality_surface_hint = NON_RATIONAL_POSSIBLE
→ المطابقة تقوي فرضية غير العاقل
```

**تأثير الترخيص**:
```

  → يحتاج دليل معجمي: كتب ← كتاب
  → مسار مرشح المفرد مفتوح
  → الترخيص الكامل مؤجل للمعجم
```

## الضمانات المعمارية

### 1. لا استخراج جذر مبكر
```
U₈ لا يرى السطح مباشرة
U₈ لا يرى protected_core مباشرة

```


### 4. قابلية التتبع الكاملة
```
كل وحدة تتتبع إلى U₇-B

كل رفع ترخيص له دليل
```

## الملخص

U₇-C يُقدّم **حماية مستوى الجملة** لتكمل **حماية مستوى الكلمة** في U₇-B.

**المبدأ الأساسي**: بعض العلامات لا يمكن فهمها إلا في سياق مطابقات متعددة الكلمات.

**الفصل الدستوري**: ملاحظة المطابقة ≠ الحكم النحوي

**الخطوة التالية**: تنفيذ دوال كشف المطابقة (المرحلة 4) لملء الحواف ورفع الترخيصات بناءً على الدليل.
