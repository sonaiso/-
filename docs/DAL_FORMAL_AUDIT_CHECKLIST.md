# DAL_FORMAL_AUDIT_CHECKLIST

**نموذج تدقيق برهاني: تغطية الدال الشكلي وحده (Dal-only Formal Audit)**

> **الغاية**: إثبات — بنداً بنداً، بأدلة من الكود — أن مشروع `dal_core` يغطي **اللفظ المفرد المشكَّل فقط** (الدال الشكلي) دون أي انتقال للمعنى (المدلول/المراد).
>
> **طريقة الاستعمال**: لكل بند ضع `PASS` / `FAIL` / `PARTIAL` في عمود الحالة، واملأ خلية الأدلة بمرجع `file:line` أو اختبار `tests/...`. كل بند بلا دليل = `FAIL` افتراضياً.
>
> **مبدأ حاكم**: لا ادعاء بلا شاهد رقمي قابل لإعادة الإنتاج.

## الصيغة الحاسمة

> يجوز علمياً ادعاء «تغطية الدال وحده شكلاً» إذا وفقط إذا تحقق:
>
> **Soundness ∧ Traceability ∧ Coverage ∧ ¬SemanticLeak**
>
> أي نقص في أحد هذه الأربعة يُسقط دعوى "الجامع المانع الشكلي".

## ملحق: كيف تُملأ هذه القائمة

1. لكل بند، شغِّل grep/test مناسباً واملأ خلية الدليل بصيغة `path/file.py:NN-MM` أو `tests/.../test_x.py::test_y`.
2. البند بلا دليل ملموس = `FAIL`.
3. عند وجود فجوة، افتح Issue يحمل وسم `dal-audit:<section>:<id>` (مثل `dal-audit:F:F8`).
4. لا تُغلق Issue إلا بـ PR يضيف:
   - تعديل كود/اختبار يحقق البند، **و**
   - تحديث هذا الملف بـ `PASS` + المرجع.
5. أعد حساب المجموع في J بعد كل دفعة إصلاحات.
